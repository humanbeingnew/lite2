# Lite 문단 요약기 V39rr

V39rr은 V38의 **정보 단위 재조합형 요약**을 유지하면서 전체 압축 목표를 **원문의 35%**, 허용 범위를 **30~45%**로 조정한 버전입니다.

## 핵심 설계
- 전체 원문을 하나의 길이 예산으로 처리
- 핵심 주장 / 원인·영향 / 근거·사례 / 숫자 / 결론을 별도 정보 단위로 평가
- 문장 전체를 단순히 잘라내는 대신 필요한 절과 사실을 짧게 재구성
- 숫자와 고유명사를 우선 보존하되 주변 숫자 나열은 핵심 사실보다 낮게 평가
- 짧은 2~4문장 기사도 한 문장으로 과압축되지 않도록 후보를 추가하고 30~45% 범위를 확인
- 월간 사용자·신규 설치처럼 분산된 통계를 하나의 핵심 통계 후보로 묶음
- 장문 기사에서 첫 주제와 마지막 결론을 구조적으로 확인
- 대조 설명 + 대표 사례 + 결론이 있는 글은 하나의 핵심 흐름 후보로 묶음
- 최종 출력에서 세미콜론 병합 흔적을 문장 경계로 정리
- URL 본문 가져오기와 Cloudflare Worker 구조 유지
- 외부 AI API와 유료 요약 서비스 없음

## 목표
기본 목표는 원문의 약 35%입니다. 실제 결과는 정보 구조에 따라 30~45% 범위에서 결정됩니다. 비율만 맞추기보다 핵심 주장, 숫자, 원인·영향, 대표 사례, 결론을 우선 보존합니다.

## 실행
```bash
npm install
npm test
npm run dev
npm run deploy
```

Cloudflare Workers + Assets 배포 구조이며, Python 설치는 필요하지 않습니다.
